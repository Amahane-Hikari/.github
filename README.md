| 文件 | 用途 |
| --- | --- |
| [profile/README.md](profile/README.md) | 组织公开首页 |

| [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md) | 默认 PR 模板 |

## 生效范围

GitHub 将本公开仓库中的受支持文件作为组织仓库的默认社区文件；目标仓库自己的同类文件优先。若目标仓库已有 Issue 模板或模板配置，其整个 Issue 模板目录优先，不会与这里的模板合并。

默认文件不会被复制到各项目源码中。许可证不继承：请查看各项目自己的 LICENSE 与素材授权。本仓库不设置统一的产品支持周期、响应时限或部署承诺。

官方说明：[默认社区文件](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)。

## 维护

添加或迁移项目时更新组织首页；修改默认文件时检查是否适用于不同语言和运行环境的仓库。项目的构建、测试和运行命令由项目自己的文档定义。
